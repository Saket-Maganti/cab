# Related Work Reframe, No-Run Draft

CAB should be positioned as a paired controlled-perturbation benchmark design for tool-using agents, not as the first benchmark to notice that agents fail or the first robustness benchmark. Existing agent benchmarks evaluate multi-step task success, tool use, web or API interaction, and process traces [TODO: verify citations from bibliography].

The narrower gap is that final-success leaderboards can be compared against paired perturbation scores under named intervention families. CAB's intended contribution is the combination of clean/intervention pairing, intervention-family taxonomy, ACRS-style ranking-instability measurement, and conservative validity governance. This contribution remains a design claim until provider-backed results and human validation exist.

Robustness and adversarial evaluation already cover many forms of stress testing [TODO: citation]. CAB should not claim novelty for "agents are brittle." It can claim a planned protocol for testing whether brittleness changes rankings in a controlled, paired setting.

Process-vs-outcome evaluation motivates trajectory metrics, but CAB's trajectory claims remain unsupported without real trajectories and human audit [TODO: citation]. ACRS should be described as a compact diagnostic summary rather than a deep method.

The strongest limitation to acknowledge is synthetic/template validity. Human validation of intervention isolation is a planned defense, not completed evidence. Any use of "causal" should be framed as intended controlled perturbation, with C10 marked pending.
