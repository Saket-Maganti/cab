\section{Conclusion}

\benchmark is designed to evaluate not only whether tool-using agents succeed, but which skills survive targeted perturbation. The paper's central hypothesis is that final task success can overestimate robust agent competence by conflating planning, tool use, memory, observation interpretation, recovery, and stopping behavior. The benchmark operationalizes this hypothesis through paired clean and intervention instances, \acrs, and trajectory-level diagnostics.

This draft does not yet claim final empirical support. The next milestone is to run the frozen benchmark with realistic LLM-backed agents, complete human validation, update the claim ledger, and replace all bracketed placeholders with reproducible evidence.
