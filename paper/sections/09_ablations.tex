\section{Ablations}

The planned ablations evaluate whether simple scaffolds improve causal robustness: explicit self-checking, planner-executor prompting, uncertainty-aware final answers, memory verification instructions, and recovery-specific tool-use policies. The analysis should report improvements, regressions, cost, latency, tool overuse, and family-specific effects.

No ablation result is claimed in this draft. This section exists to prevent the paper from over-attributing robustness failures to model architecture when prompt or scaffold changes might explain part of the effect. The planned evidence is tracked by \claimref{C6}.
