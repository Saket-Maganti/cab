\section*{NeurIPS Checklist Draft}

\begin{enumerate}[leftmargin=*]
    \item \textbf{Claims.} All scientific claims are tracked in \texttt{docs/CLAIM\_LEDGER.md}. Unsupported claims are marked planned or placeholder.
    \item \textbf{Limitations.} Limitations are discussed in Section~10 and \texttt{docs/ETHICS\_AND\_LIMITATIONS.md}.
    \item \textbf{Reproducibility.} Code, configs, schemas, generated data, trajectories, score scripts, analysis scripts, and run metadata are part of the repository scaffold. Final reported runs must include artifact paths.
    \item \textbf{Data.} Default data is synthetic. Dataset and benchmark cards document intended use, construction, fields, metrics, limitations, licensing TODOs, and maintenance plans.
    \item \textbf{Human validation.} Not yet run. Required before strong claims about label quality or intervention validity.
    \item \textbf{Compute and cost.} Smoke tests do not require paid services. Main LLM experiments must report provider, model version, date, sampling settings, cost, and latency.
    \item \textbf{Ethics.} Default tools do not send real email, make bookings, or access private data.
\end{enumerate}
