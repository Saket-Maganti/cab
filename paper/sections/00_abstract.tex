\begin{abstract}
Tool-using language agents are increasingly evaluated by final task success, but such scores conflate planning, tool selection, memory use, observation interpretation, recovery, and stopping behavior. We introduce \benchmark, an interventional benchmark that pairs clean agent tasks with controlled perturbations targeting individual skill components. In the planned final study across [N] tasks, [M] intervention instances, and [K] agents, we will test whether clean success overestimates robust competence by [X] points on average, and whether model rankings under clean success correlate only [rho] with rankings under causal robustness. We propose Agent Causal Robustness Score (\acrs) and a suite of trajectory-level diagnostics designed to expose failures hidden by final-answer scoring. \benchmark provides a reproducible evaluation framework for measuring not only whether agents succeed, but which agentic skills survive under controlled environmental stress.
\end{abstract}
