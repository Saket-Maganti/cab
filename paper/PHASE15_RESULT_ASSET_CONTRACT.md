## Evidence gate

The strict exporter has no `allow_*` override. Every supplied run must have:

- a valid `cab_run_manifest_v2`;
- `status: audited`;
- `evidence_class: PAPER_ELIGIBLE_EVIDENCE`;
- `scientific_evidence: true`;
- `paper_eligible: true`;
- matching literal declarations in run metadata;
- complete trajectories and required run artifacts; and
- no `INCOMPLETE_RUN.json`.

The complete bundle additionally requires:

- a Main-500 source with at least three eligible non-oracle models, reportable
  clustered rank bootstrap replicates, complete matched transition profiles,
  and measured cost/runtime;
- an audited naturalistic-transfer source with verified provenance and license,
  passed privacy, PII, and prompt-injection reviews, and a documented removal
  procedure;
- an audited frozen-task ablation source with explicit ablation metadata;
- blinded human scorer validation with a passed threshold and explicit
  sensitivity scenarios; and
- a genuine two-reviewer intervention-validity report with adjudication and
  `C10: PASS`.

If any requirement is missing, preflight fails before the output directory is
created. Export never changes the claim ledger and the bundle manifest records
`claim_promotion_performed: false`.

## Provider-free inspection

List the complete design-only registry:

```bash
PYTHONPATH=src python3 scripts/export_phase15_paper_assets.py --list-contract
```

This command does not inspect runs or write result assets.

Preflight future audited sources without writing:

```bash
PYTHONPATH=src python3 scripts/export_phase15_paper_assets.py \
  --preflight-only \
  --source main=results/<audited-main500> \
  --source naturalistic=results/<audited-naturalistic> \
  --source ablation=results/<audited-ablation> \
  --source scorer_validation=results/<audited-scorer-validation> \
  --source intervention_validity=results/<audited-intervention-validity>
```

Do not replace any source above with a fixture, mock, oracle-only, dry run,
preliminary run, interrupted run, or unaudited provider output.
