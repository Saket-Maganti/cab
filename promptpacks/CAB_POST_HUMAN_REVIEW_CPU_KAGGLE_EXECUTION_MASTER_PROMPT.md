# 16. Mandatory arbitrary-name ZIP auto-detection

This is a hard requirement.

Every Kaggle CPU and T4×2 notebook must accept an attached ZIP:

- with any filename;
- under any Kaggle dataset name;
- under any nested `/kaggle/input/<dataset>/...` directory;
- with any top-level archive folder name;
- after the user renames the ZIP;
- when more than one unrelated ZIP is attached.

## 16.1 Discovery algorithm

Implement a shared tested utility, for example:

```text
src/causal_agent_bench/kaggle_input_discovery.py
```

At notebook startup:

1. recursively scan `/kaggle/input` at bounded depth;
2. enumerate directories and `.zip` files case-insensitively;
3. optionally accept an explicit override environment variable;
4. inspect ZIP member names without extracting;
5. score candidates by content sentinels;
6. reject path traversal, absolute paths, symlinks, devices, and ZIP bombs;
7. compute archive SHA-256;
8. select a unique highest-confidence candidate;
9. fail with a readable inventory if selection is ambiguous;
10. safely extract to a hash-named directory under `/kaggle/working`;
11. recursively locate the logical root by sentinel files;
12. verify the internal bundle manifest and hashes;
13. record the detected archive path and hash;
14. never depend on the external filename.

## 16.2 Repository bundle sentinels

Useful sentinels include a weighted combination of:

```text
pyproject.toml
src/causal_agent_bench/
scripts/
configs/
reports/reviewer_ready_v2/ACTIVE_PATH_REGISTRY.json
reports/reviewer_ready_v2/SCIENTIFIC_FREEZE_V2.json
data/manifests/
environment/kaggle_environment.json
CAB_KAGGLE_INPUT_MANIFEST.json
```

Do not select a candidate from one weak sentinel alone.

## 16.3 Run-output bundle sentinels

Detect run-output bundles by content such as:

```text
CAB_KAGGLE_OUTPUT_MANIFEST.json
run_manifest.json
execution_authorization.json
trajectory or shard manifest
raw trajectory directory
result schema version
input-lock hash
```

Classify:

```text
COMPACT20_OUTPUT
SCALE100_OUTPUT
RAAC_OUTPUT
NATURALISTIC_OUTPUT
FINAL_ANALYSIS_INPUT
```

by manifest content, never filename.

## 16.4 Ambiguity behavior

If two candidate archives have equal valid scores and different content:

```text
FAIL_CLOSED_AMBIGUOUS_KAGGLE_INPUT
```

Print a private-safe candidate table with:

- path;
- size;
- SHA-256;
- detected bundle type;
- sentinel score.

Do not guess.

## 16.5 Auto-detection tests

Test at least:

- expected filename;
- random filename;
- spaces and Unicode in filename;
- uppercase `.ZIP`;
- nested Kaggle dataset folder;
- arbitrary archive root folder;
- no top-level folder;
- two unrelated ZIPs;
- two valid identical copies;
- two conflicting valid bundles;
- malicious `../` entry;
- absolute path entry;
- oversized expansion ratio;
- truncated ZIP;
- valid raw directory instead of ZIP;
- output ZIP renamed as input;
- input ZIP renamed as output;
- explicit override;
- override with wrong type.

Use random names in tests to prove no filename dependence.
