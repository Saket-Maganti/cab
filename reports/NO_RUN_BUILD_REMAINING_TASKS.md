# No-Run Build Remaining Tasks

## Must Do Before Manual Review

- Confirm reviewer owners and instructions.
- Freeze the candidate manifest used for review.
- Decide whether any candidates should be replaced before annotation.

## Must Do Before API/Provider Run

- Complete Compact-20 task and gold-policy reviews.
- Exclude ambiguous or non-isolated rows.
- Obtain explicit live-run approval.
- Create an approved config from the non-runnable template.
- Run provider preflight with no secret leakage.

## Must Do Before Workshop Paper

- Complete at least preliminary provider outputs.
- Run scorer sanity.
- Fill no fake results.
- Keep limitations and claim ledger visible.

## Must Do Before NeurIPS D&B

- Larger provider-backed runs.
- Human validation with agreement.
- Supported C1-C8/C10 claims as applicable.
- Eligible paper assets.
- Release artifact and reproducibility package.
- Advisor/coauthor signoff.

## Do Not Do Now

- Do not run main_200/main_500.
- Do not call providers.
- Do not run local LLMs.
- Do not delete/move docs without a reference check.
- Do not promote claims from templates or static reports.
