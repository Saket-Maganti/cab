# External pilot guide

An external researcher should:

1. install CAB in a clean environment;
2. run `cab env doctor` and the fixture reproduction;
3. author one public fixture task;
4. compile and validate it;
5. implement or inspect one example plugin;
6. submit a fixture agent to the mock evaluator;
7. record commands, friction, defects and suggested documentation changes.

Use the issue templates without including secrets, protected tasks or personal
reviewer data. A project maintainer may reproduce and classify the report. CAB
does not count a pilot until a real external participant submits a consented
receipt.
