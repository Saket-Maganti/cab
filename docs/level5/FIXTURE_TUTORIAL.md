# End-to-end fixture tutorial

The public arithmetic fixture compiles one controlled tool-warning intervention.
Its target hash stays private to the authoring contract. The run planner expands
20 task IDs across one fixture model and policy, then assigns two disjoint
shards.

Internal reproduction interrupts after seven completed units, reloads the same
manifest/checkpoint, finishes the remaining 13 and merges in manifest order.
It verifies every CAS object, runs the 18-case chaos matrix, audits a mock
submission, builds a two-node evidence graph and verifies a development
certificate.

Inspect `/tmp/cab_level5_reproduction/reproduction_receipt.json`. It must say
`INTERNAL_FIXTURE_ONLY` and `independent_reproduction=false`.
