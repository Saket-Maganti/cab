# Level-5 gate

`cab level5 check` reads the versioned build state and evaluates foundation
capabilities separately from genuine counts.

The build-now target is:

```text
CAB_LEVEL5_PLATFORM_FOUNDATION_COMPLETE
HUMAN_VALIDATION_REQUIRED
LIVE_EVIDENCE_REQUIRED
EXTERNAL_REPLICATION_REQUIRED
PROTECTED_EVALUATOR_PILOT_REQUIRED
COMMUNITY_PILOT_REQUIRED
```

`CAB_LEVEL5_COMPLETE` additionally requires genuine human rows, live
trajectories, audited runs, paper-eligible assets and supported claims, an
independent external reproduction, protected-evaluator and community pilots,
zero critical red-team issues and zero committed protected payloads.
