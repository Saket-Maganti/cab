# Red-team programme

The programme tests benchmark leakage/memorization, scorer and answer-format
exploitation, abstention/retry/budget gaming, RAAC over-triggering, hidden-label
access, prompt/tool injection, task-ID leakage, artifact tampering, evaluator
escape, collusion and suspicious performance jumps.

Fixture outputs cover automatic detectors; policy-only attacks remain manual
review cases. Findings record severity, reproduction, owner, mitigation,
accepted risk and release-blocker status. Critical unresolved issues block the
Level-5 gate.

Fixture detections are engineering evidence, not a genuine evaluator security
pilot. The threat model and campaign must be repeated in the production-like
sandbox before protected evaluation release.
