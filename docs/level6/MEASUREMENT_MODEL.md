# CAB Level-6 Measurement Model

The construct map covers planning, tool use, memory, observation handling,
evidence integration, stopping, recovery, calibration, abstention, and
robustness. Each construct is linked to task demand, intervention, observable
behavior, trajectory evidence, endpoint, and a bounded claim. A task score is
not treated as direct observation of an unrestricted latent capability.

Content, convergent, discriminant, criterion, predictive, and known-groups
validity require genuine evidence before conclusions. Reliability is decomposed
across task, model, intervention family, repeat, scorer, reviewer, and residual
facets. The G-theory design is model × task × intervention × scorer × repeat and
reports both relative G and absolute dependability coefficients.

The prepared invariance sequence is configural, metric, scalar, partial,
model-family, domain, and intervention-family invariance. DIF tooling includes
logistic regression, Mantel-Haenszel where applicable, a hierarchical-item-model
contract, and multiple-testing correction. Bootstrap/Bayesian analysis must
propagate scorer, reviewer, adjudication, and exclusion uncertainty.

All committed outputs are labeled fixtures. CAB reports no real invariance, DIF,
generalizability, or construct-validity result until governed data exists.
