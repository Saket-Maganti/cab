# Authorized execution runbook

No live execution is authorized by the engineering freeze. First verify the scientific freeze,
complete genuine review and C10, lock the slice, and pass the content-bound final run gate.

Once independently authorized, use this order:

1. Compact offline fixture rehearsal.
2. One-task live smoke.
3. Compact-20 standard policy.
4. Compact-20 RAAC-Light.
5. Scorer audit.
6. Decision gate.
7. Scale-100 standard.
8. Scale-100 RAAC-Light.
9. Staged RAAC ablations.
10. Transfer study.
11. Final analysis.

Stop on any packet, scorer, endpoint, analysis-plan, system-identity, approval, or slice-lock hash
mismatch. Never treat the fixture rehearsal as genuine or paper-eligible evidence.
