## Paper Integration Notes

- Use the cited papers to establish context, not to claim that prior work lacks every feature.
- The novelty claim should be narrow: paired clean/intervened task instances designed to isolate named tool-using agent skills.
- For any future addition, record whether the paper reports trajectory logs, component metrics, perturbation families, human validation, and reproducibility artifacts.
- Run `make paper-check` to verify bibliography keys for related work.
