# Naturalistic Task Authoring Guide

Status: authoring guide only.

## Requirements

- Bundle all files needed for local execution.
- Use public, licensed, or self-authored content.
- Record provenance and license.
- Define clean and intervention instances.
- Map each intervention to a CAB family.
- State expected final answer and acceptable uncertainty behavior.
- Mark human review required for ambiguous answers.

## Exclusions

- private data,
- scraped data without permission,
- live websites,
- unversioned external files,
- tasks that require provider memory or external credentials.
